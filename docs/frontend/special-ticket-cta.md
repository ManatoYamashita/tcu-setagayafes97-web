# 著名人企画LPのモバイルチケット導線

## 目的

`/special/[id]` では、ヒーローからチケット販売欄までの距離が長い。さらに従来の
`TicketTable` は券種を横方向へ並べていたため、390px幅では購入ボタンが初期表示位置から
横にも外れていた。チケット購入を主要行動として常に発見でき、販売情報へ到達した後は
本文側の操作へ自然に役割を渡す。

## 表示ルール

- `buttonUrl` を持つ券種が無い場合、固定CTAは表示しない。
- 購入可能な券種が1つの場合、固定CTAから販売ページを直接開く。
- 購入可能な券種が複数の場合、固定CTAは `#special-tickets` へ案内し、券種を勝手に選ばない。
- 下書きプレビュー中は `DraftPreviewBanner` と競合するため、固定CTAを表示しない。
- `md` 以上では固定CTAを非表示にし、従来の比較表を維持する。

遷移先の決定は Server Component 側で `resolveMobileTicketCta()` を実行する。Client Componentへ
チケット配列やリッチテキストを渡さず、`href`・ラベル・券種名・外部リンク判定だけを渡す。

## モバイルレイアウト

`TicketTable` は同じ入稿データを次の2表現へ分ける。

- モバイル: 券種ごとの縦カード。料金・販売期間・販売方法・注意事項・購入ボタンを上から読む。
- デスクトップ: 券種を列にした比較表。複数券種の横比較を優先する。

固定CTAは `z-30`、共通ヘッダーは `z-40`、モバイルメニューは `z-50` とする。画面端には
貼り付けず、左右16pxを空ける。下端は `env(safe-area-inset-bottom)` に12pxを加え、iPhoneの
ホームインジケーターと重ねない。ヒーローのモバイル下余白はCTA表示時だけ `pb-32` とし、
ロゴと主催者名を覆わない。

## 退避条件

`MobileTicketCTA` は次の要素を `IntersectionObserver` で監視する。

- `[data-special-ticket-purchase]`: 本文側の購入ボタン
- `footer`: 共通フッター

固定ドック自身の高さを除いた表示領域へ対象が入ったら固定CTAを外す。チケット節の見出しが
見えただけでは外さない。モバイルカード内の購入ボタンがまだ画面外にある間、購入導線を
失わないためである。`IntersectionObserver` 非対応時は、退避より購入導線の維持を優先する。

## アクセシビリティ契約

- 購入操作はURL遷移なので `<a>` を使う。
- 固定CTAは最低56px、本文側CTAは最低44pxの高さを持つ。
- 外部リンクは視覚アイコンに加え、アクセシブルネームへ「外部サイトが開きます」を含める。
- フォーカス表示は `primary-700` の3pxアウトラインと3pxオフセットを使う。
- 固定CTAがフォーカス中の場合、監視対象が表示されてもアンマウントせずフォーカスを維持する。
- CTA面は `primary-600`、文字は白とし、WCAG 2コントラスト比 `7.45:1` を確保する。
- 押下時の縮小は `scale(0.96)`、150msとし、`prefers-reduced-motion` では無効化する。

## 検証

最低限、320×640・390×844・1280×900で確認する。

- 320px幅で横スクロールが発生しない。
- ヒーローコピーと固定CTAの矩形が重ならない。
- チケット節の冒頭では固定CTAが残り、本文側購入ボタンが見えた時だけ外れる。
- フッター表示中は固定CTAが外れる。
- デスクトップでは固定CTAとモバイルカードが `display: none`、比較表が表示される。
- キーボードフォーカス時にアウトラインが見える。
