# 著名人企画の告知セクション（SpecialGuestSection）

トップページ（Hero の直下）と `/events` の最下部に置く、著名人企画 LP への導線（#414）。
実装は `src/components/special/SpecialGuestSection.tsx`、文言と画像は `src/data/special-banner.ts`。
`/events` 冒頭の音楽ポスター風バナーは別物で、[events-special-banner.md](./events-special-banner.md) を参照。

## 構成

横長の写真の右上を四分円で欠き、右側へ見出し・本文・CTA を置く。

| 要素        | 中身                       | 備考                                                                   |
| ----------- | -------------------------- | ---------------------------------------------------------------------- |
| 見出し `h2` | 出演者ロゴ＋右へ伸びる横罫 | ロゴの `alt`（出演者名）が見出しのアクセシブル名。横罫は `aria-hidden` |
| 分類ラベル  | `著名人企画`（縦書き）     | `writing-mode: vertical-rl`                                            |
| 本文        | 日時・会場（1要素 = 1行）  | `specialBanner.headline`                                               |
| CTA         | `詳しくはこちら →`         | `/special/[id]` へ                                                     |

画面幅ごとの配置:

- 〜767px: 縦積み。写真（4:3）→ テキスト
- 768px〜: 12列グリッド。写真（3:2）が左の 7列（lg 以上は 8列）、テキストが残りの列。
  見出しだけを `-ml-*` で左へ引き出し、ロゴの頭を写真の右端へ重ねる

DOM 順は「見出し → 本文 → CTA → 写真」で固定し、縦積みのときだけ写真に `order-first` を付けて
見た目を入れ替える。DOM を並べ替えると h2 より先に写真が読み上げられる。

## 判断の記録

### チケット情報を載せない

以前は一般券と学内生券の明細をこのセクションに並べていた。参考レイアウトに合わせて日時・会場だけにし、
券種と販売方法は LP のチケット表へ任せた。**戻す場合は券種を必ず両方載せること**
（片方だけだと、一般来場者が学内の手売りを自分向けと誤読する。`special-banner.ts` 冒頭のコメント）。

### 右上の欠けは mask で作る

`.special-guest-notch`（`globals.css`）が `radial-gradient` の `mask-image` で写真の右上を透かす。
円を背景色で塗る方式だと、トップ（`.hero-about-bg` のグラデーション）と `/events`（白いシート）で
塗る色が変わり、グラデーションの上では色が合わない。mask なら背景を問わない。
半径は `--special-guest-notch` で、3.5rem / md 5rem / lg 7rem。

### 写真に重なるロゴの輪郭

重なる位置は MON7A の暗い衣装の上になり、黒いロゴが沈む。md 以上（重なる幅）だけ
白い `drop-shadow` を付けて輪郭を保つ。縦積みでは重ならないので付けない。

### 会場名を語の途中で折り返さない

会場名「世田谷キャンパス第1アリーナ」（14字）は、`text-xl` のままだと 768px と 1024px で
「アリー｜ナ」と折り返した（2026-10-06 実測）。列幅に合わせて md `text-base` / lg `text-lg` /
xl `text-xl` へ段階的に詰めて1行に収めている。**文言を長くしたら 768px と 1024px で確認すること。**

### 参考レイアウトのページャーは置かない

参考画像にはスライドのページャー（01 02 …）があるが、企画が1件しかなく押す先が無いため省いた。

## `/events` での遅延描画

`/events` では `.deferred-section--special` が `content-visibility: auto` の推定高さを持つ。
写真が列幅に比例して伸びるため、推定高さを md / lg / xl で分けている（実測値は `globals.css` のコメント）。
レイアウトを変えたら `/events` で実測し直すこと。推定が実寸から離れると、入場モーションの
ScrollTrigger が画面外の推定値でトリガー位置を測る。
