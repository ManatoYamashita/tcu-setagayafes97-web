# Accessページ デザイン・実装方針

## 目的

来場者が会場所在地と推奨経路を短時間で把握し、迷わず外部地図へ移動できるAccessページを提供する。

## 情報の優先順位

1. 会場名・住所・Google マップへの導線
2. 推奨経路（尾山台駅から徒歩）
3. バスによる代替経路
4. 駐車場・駐輪場・混雑に関する注意
5. 当日用キャンパスマップの公開状況

## UIルール

- Heroは既存の共通Header直下へ余白なく全幅で配置し、上段を見出し・説明・CTA、下段を交通案内動画とする。
- Hero外側には最大幅、角丸、背景色の枠を設けず、見出しセクションの内容は高さ方向の中央へ配置する。
- Hero動画の上には会場名や徒歩時間のフローティングカードを重ねない。
- Hero動画の上下端には白から透明へ抜けるグラデーションを重ね、左右端には適用しない。
- Hero動画は`public/videos/access-tcu-setagaya.webm`を使用し、装飾目的として無音で1回だけ自動再生し、再生後は最終フレームで停止する。
- 動きを減らす設定では動画を読み込まず、`public/images/video-posters/access-tcu-setagaya.webp`を表示する。
- 動画領域は16:9の表示比率を予約し、読み込み時のレイアウトシフトを防止する。
- 主要CTAはテキストを伴うリンクとし、44px相当以上の操作領域を確保する。
- 主要CTAのラベルは途中で折り返さない。
- 経路一覧は意味のある順序付きリストで表現する。
- 地図iframeには内容が分かる`title`を付け、遅延読み込みする。
- 色だけに依存せず、アイコン・見出し・説明文を併用する。
- モバイルでは徒歩時間や乗車時間を本文の下へ自然に折り返す。
- 外部地図が利用できない場合でも、住所と経路情報だけで来場判断ができる構造にする。
- 所在地欄は地図と住所を罫線で簡潔に区切り、装飾アイコン、英字ラベル、カード状の影を使用しない。

## コンテンツ管理

- 住所、交通経路、地図URL、表示文言は`src/data/access.ts`へ集約する。
- 交通経路は東京都市大学公式の交通案内を基準とする。
- 駐輪場など未確定の情報は推測で公開せず、準備中であることを明示する。
