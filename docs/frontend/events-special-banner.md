# `/events` の著名人企画バナー

## 背景と解決

企画一覧の冒頭にあった導線は「Special / 著名人企画」の文字だけで、出演者や公演内容が分からなかった（#380）。`SpecialEventBanner` では「著名人企画」「MON7A」「スペシャルパフォーマンス」を示し、既存のアーティスト写真を右側に配置する。角丸とグラデーションの広告カード、続く淡色の細い帯はどちらも企画の強さが伝わらなかった。公式ロゴと写真を主役にした、紫の単色面の音楽ポスターとして組み直した。

## 実装の契約

- 表示内容は `src/data/special-banner.ts` を参照する。名前、画像、企画 ID を別の定数へ複製しない。
- リンク先は `/special/${eventId}`。`/special` の転送を経由せず、公開中の著名人企画 LP に直接送る。
- 出演者名は既存の透過ロゴを見出しに置く。写真も既存の最適化済み AVIF を `AppImage` で描く。写真は装飾として空の `alt` にする。
- 小画面でも写真は右側に残す。写真の左辺だけを斜めに切り、文字と写真を重ねない。幅 320px でもロゴ・副題・リンクを読めるようにする。
- バナーの実測高は 320px・375px 幅で 172px、1440px 幅で約 216px。角丸、影、グラデーション、装飾アニメーションは加えない。
- バナー直後の絞り込みとの間隔は 24px。バナーと一覧を一画面で見渡せるようにする。
- バナーは `Suspense` 境界の外に置き、`/events` の静的 HTML に残す。

## 確認点

320px・375px・1440px で文字の重なり、写真の見え方、リンクのフォーカスを確認する。axe の対象バナー検査も実施する。画像配信は `pnpm check:images`、静的 HTML の契約は `pnpm build` 後の `assert-events-static-html.mjs` で確認する。
