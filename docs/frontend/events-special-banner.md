# `/events` の著名人企画バナー

## 背景と解決

企画一覧の冒頭にあった導線は「Special / 著名人企画」の文字だけで、出演者や公演内容が分からなかった（#380）。`SpecialEventBanner` では「著名人企画」「MON7A」「スペシャルパフォーマンス」を見出しとして示し、既存のアーティスト写真を右側に配置する。

## 実装の契約

- 表示内容は `src/data/special-banner.ts` を参照する。名前、画像、企画 ID を別の定数へ複製しない。
- リンク先は `/special/${eventId}`。`/special` の転送を経由せず、公開中の著名人企画 LP に直接送る。
- 写真は既存の最適化済み AVIF を `AppImage` で描く。見出しで出演者名を読めるため、バナー内の写真は装飾として空の `alt` にする。
- 小画面でも写真は右側に残す。文字と写真の境界は背景グラデーションで作り、写真の上に長い文言を載せない。
- バナーは `Suspense` 境界の外に置き、`/events` の静的 HTML に残す。

## 確認点

320px・375px・1440px で文字の重なり、写真の見え方、リンクのフォーカスを確認する。画像配信は `pnpm check:images`、静的 HTML の契約は `pnpm build` 後の `assert-events-static-html.mjs` で確認する。
