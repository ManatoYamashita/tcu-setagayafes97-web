# `/events` の著名人企画バナー

## 背景と解決

企画一覧の冒頭にあった導線は「Special / 著名人企画」の文字だけで、出演者や公演内容が分からなかった（#380）。`SpecialEventBanner` では「著名人企画」「MON7A」「スペシャルパフォーマンス」を示し、既存のアーティスト写真を右側に配置する。最初の大きな角丸と暗色グラデーションは汎用的な広告カードに見えたため、薄い紙面のような横長の告知へ改めた。

## 実装の契約

- 表示内容は `src/data/special-banner.ts` を参照する。名前、画像、企画 ID を別の定数へ複製しない。
- リンク先は `/special/${eventId}`。`/special` の転送を経由せず、公開中の著名人企画 LP に直接送る。
- 出演者名は既存の透過ロゴを見出しに置く。写真も既存の最適化済み AVIF を `AppImage` で描く。写真は装飾として空の `alt` にする。
- 小画面でも写真は右側に残す。文字と写真の境界は罫線で明確に区切り、写真の上に文字を載せない。
- バナーの高さは 320px 幅で 172px、広い画面でも 208px を基準とする。角丸、影、グラデーション、装飾アニメーションは加えない。
- バナーは `Suspense` 境界の外に置き、`/events` の静的 HTML に残す。

## 確認点

320px・375px・1440px で文字の重なり、写真の見え方、リンクのフォーカスを確認する。画像配信は `pnpm check:images`、静的 HTML の契約は `pnpm build` 後の `assert-events-static-html.mjs` で確認する。
