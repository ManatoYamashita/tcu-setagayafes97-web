## 出典と収録範囲

出典は実行委員会の「過去の世田谷祭」（`https://archive.setagayafes.org/`）。2026-10-06 に全回を curl で確認した。

| 回         | 扱い                                                                                  |
| ---------- | ------------------------------------------------------------------------------------- |
| 第76〜95回 | `archive.setagayafes.org/<序数>/`（`81st` `82nd` `83rd` `91st` `92nd` `93rd` に注意） |
| 第96回     | `96th.setagayafes.org`（WordPress 版）。アーカイブの一覧ページもこちらを指している    |
| 第87回     | **載せない。** サイトが現存せず（404）、アーカイブでも「閲覧できません」              |
| 第75回     | **載せない。** 実体はあるが、アーカイブの一覧ページでコメントアウトされている         |

開催年は「回数 + 1929」（第96回 = 2025年）。各回のサイト本文の年と照合済み。

## サムネイル

- 原本は `archive.setagayafes.org/img/<序数>.png`（各回トップのスクリーンショット）。
  **第94回・第95回はアーカイブ側の画像が 404** だったため、実サイトを agent-browser で
  1000×678 で撮影して補った。第94回はローディング画面が約10秒残るので、待たずに撮ると真っ黒になる。
- 原本の PNG は計 9.8MB あったため、幅 960px の WebP（q90）へ縮めて `assets/source/` に置いた（計 1.7MB）。
- 縦横比が回ごとに違う（836×883 〜 1448×1086）ので、**4:3 へ切り抜く**。回数やロゴはヘッダーに
  あるため、切り抜きの基準は上端にする。そのために `scripts/optimize-static-images.mjs` が
  manifest の `position` を sharp へ渡すようにした（省略時は従来どおり中央）。
- box は 560×420。表示幅が最大になるのは2列の上限（viewport 639px）で約272px、その2倍。
  20枚の合計は約35万B。すべて lazy で、ファーストビューの予算には入らない。

## 画面の設計

- 列数は 2 → 3（sm）→ 4（md）→ 5（lg）。lg では 20件がちょうど 5×4 に収まる。
- 画像はキャプション（回数・年）と同じ情報しか持たないので `alt=""`。
  リンク名は「第89回 2018年（新しいタブで開きます）」。回数と年の間の空白は、
  flex の中でも読み上げを区切るために明示している（無いと「第90回2019年」と続けて読まれた）。
- 白地のスクリーンショットが背景に溶けないよう、画像に `outline-gray-900/10` の縁を付けている。
- 入場演出は付けない。

## 検索除外との関係

過去回の全ホストは `X-Robots-Tag: noindex` 付与済み（[legacy-site-deindex.md](../dev/legacy-site-deindex.md)）。
同文書が禁じているのは「apex の旧パスから過去回への 301」で、通常のリンクは禁じていない。
リンクを辿らせることは、むしろ noindex の再発見を早める（同文書の `nofollow` を足さない理由と同じ）。
