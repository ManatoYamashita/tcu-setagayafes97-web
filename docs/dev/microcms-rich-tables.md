# microCMS リッチテキストのテーブル

## 入稿と表示の契約

News / Events の `content` は microCMS `richEditorV2` が返す HTML 文字列である。
表はリッチエディタのテーブルとして入稿し、出力された `<table>` をそのまま描画する。
Markdown の表記へ変換・再パースしない。

`src/app/globals.css` は News の `.prose` と Events の `.event-rich-content` に対し、
表の外枠、セルの罫線、見出しセルの背景色、狭い列での文字折り返しを指定する（#300）。
Events 詳細では `EventDetail.tsx` の本文コンテナに `.event-rich-content` を付ける。

## Aside で記事本文を編集するとき

Aside にログイン済みのブラウザーがあれば、`aside mcp` の `repl` ツール、または
`aside repl` から開いているタブを操作できる。画面の状態を確認してから実際の UI を操作し、
保存・公開後は Content API と公開ページで内容を照合する。

2026-09-30 に `events/cfc` の仮画像を削除し、4行のテーブルへ置き換えて公開した。
公開 Content API ではテーブル1件・画像0件を確認した。料金、販売日時、販売方法・場所、
開催枠が編集前の内容と一致することも照合した。

スキーマ定義・カスタムフィールド作成には別の操作上の注意がある。
詳細は [microcms.md](./microcms.md) を参照。

## 表示確認

- 表の内容は公開 Content API の HTML で確認する。
- 外枠とセル罫線は実ブラウザーで `border` の算出値と画面を確認する。
- 狭い幅では表と本文の幅、ページ全体の横スクロール幅を測る。
- ブラウザーのモバイル幅による検証は、物理スマートフォンによる確認とは区別して記録する。
