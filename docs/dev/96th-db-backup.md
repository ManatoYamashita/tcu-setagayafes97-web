SHA-256 は、リポジトリ外の安全な保管場所にある原本と照合するための値である。バックアップを移動・複製した場合は、次のコマンドで再計算して一致を確認する。

```bash
shasum -a 256 96th-wordpress-db-backup-20260824.sql
```

## 保管・取扱い

- 原本はアクセス制御されたバックアップ保管先に置き、GitHub・公開ストレージ・チャットへアップロードしない。
- ダンプには WordPress ユーザー、メールアドレス、設定値、トークン等が含まれるため、復元作業を行う担当者だけに共有する。
- 移行後も不要になった複製は保管先の保持期限に従って削除し、削除結果を保管先の監査ログで確認する。
- ダンプ内の認証情報やトークンが第三者へ共有された可能性がある場合は、復元前に該当する認証情報をローテーションする。

## 復元前チェック

1. 原本の SHA-256 が台帳の値と一致することを確認する。
2. 復元先が第96回用の隔離データベースであり、第97回本番データベースではないことを確認する。
3. 復元先のアクセス制御・バックアップ・ロールバック手順を確認する。
4. 復元後に `siteurl` / `home` が `https://96th.setagayafes.org` を指すことを確認する。

このPRでは、機密な生ダンプの代わりに本台帳と誤コミット防止の `.gitignore` ルールを追加して、バックアップの存在と完全性を追跡可能にしている。
